01

Abstract

TAVMem stores task histories in a task-action-variant library where tasks share action records. It finds a reusable task through knowledge-driven similarity retrieval. It reuses each step after an applicability check on the current UI. Steps that fail go to the base agent, and reuse resumes at the next applicable step.

Mobile GUI agents enable users to automatically access web services through mobile apps. However, these agents invoke a vision-language model at every step. Repeated model calls incur substantial cost and task latency. Reusing actions from past tasks offers a promising way to eliminate costly model calls. Existing methods often miss reuse opportunities or reuse actions incorrectly. They spend substantial time retrieving relevant tasks and checking whether they can be reused. They also store redundant action records and UI information, making memory libraries too large for mobile devices.

To address these issues, this paper presents TAVMem, a method for organizing reusable execution memory and enabling efficient action reuse in mobile GUI agents. TAVMem organizes task histories into a flexible reuse library with a task-action-variant structure, where tasks can share action records. It exports a compact and lightweight runtime library for mobile devices. TAVMem introduces a novel knowledge-driven similarity retrieval approach to locate reusable tasks. It then replays the retrieved task and employs an efficient applicability checking mechanism to decide whether each step can be reused on the current UI. Steps that fail the check are handed to the base agent, and reuse resumes seamlessly at the next applicable step.

Extensive experiments on AndroidWorld, MobileAgentBench, and MobileWorld demonstrate the effectiveness of TAVMem. Compared with agents without action reuse, it reduces model calls per task by 45.3–63.6% and mean task latency by 43.6–64.2% without compromising task success rate. It achieves reuse rates of 85.1–89.1% and reuse accuracy of 91.3–98.2%, surpassing state-of-the-art methods by 4.8–19.8% and 2.2–6.4% in relative terms, respectively. Its runtime libraries occupy only 0.952–4.07 MiB.

03

Method

TAVMem keeps a full memory library on the cloud for construction and maintenance, and exports a compact runtime library to the phone. For a new instruction, it retrieves a related task record, keeps the steps that do not need to change, and checks each stored variant against the current UI before reusing its action. The base agent handles the remaining steps, and reuse resumes afterwards. Pick a stage to jump to it.

Action Sharing and Variant Preservation

Different tasks often share a step but execute it under different UI conditions. TAVMem stores that step once as an action record and keeps each distinct execution as a variant, so the applicability check can pick the variant that fits the current screen.

04

Results

We compare TAVMem with the base agent and five memory methods on AndroidWorld (parameter changes within task templates), MobileAgentBench (everyday app tasks), and MobileWorld (cross-application workflows). All methods use the same MobileRun base agent with Qwen3-VL-8B-Instruct, build their libraries from the same frozen successful executions, and run each of 30 tasks three times.
